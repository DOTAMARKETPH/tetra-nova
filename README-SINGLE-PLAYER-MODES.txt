TETRA NOVA — SINGLE PLAYER MODES UPDATE

Files to replace in the root of your GitHub repository:
- index.html
- style.css
- script.js

New menu flow:
Start Game > Single Player > Bot Match / Endless
Bot Match > Easy / Medium / Hard

Bot Match uses the same side-by-side battle layout as online multiplayer. The opponent panel displays the NOVA BOT board, score, lines, and difficulty. The bot places pieces automatically; difficulty changes its drop speed and placement behavior. If the player tops out, the bot wins; if the bot tops out, the player wins.

Endless starts the existing solo game. Online multiplayer and existing settings/music are retained.

Upload the three files to the repository root and commit the changes. Then refresh the GitHub Pages site (a hard refresh may be needed).
